# 🧪 Автоматизация Unit-тестирования Backend-слоя приложения Stellar Burgers

Проект демонстрирует навыки покрытия ключевой бизнес-логики изолированными модульными тестами, параметризации тестовых данных и работы с метриками покрытия кода.

---

### 🛠 Стек и инструменты: Java 11, JUnit 4, Mockito, Maven, JaCoCo

---

### 📝 Описание проекта
**Stellar Burgers** — веб-приложение для заказа космических бургеров. 

**Цель работы:** Обеспечение надежности и отказоустойчивости доменной модели (класс `Burger`) на этапе разработки за счет написания поддерживаемых автотестов.

---

### 🚀 Выполненные задачи и результаты

#### 🔹 Часть 1: Проектирование и разработка автотестов
* **Изоляция зависимостей (Mocking):** Реализовала полное мокирование объектов с помощью **Mockito**. Это позволило протестировать класс `Burger` изолированно от его реальных зависимостей (`Bun` и `Ingredient`).
* **Оптимизация тест-дизайна (Data-Driven):** Применила параметризованный раннер **JUnit 4 (Parameterized)**. С помощью одного метода настроила проверку различных комбинаций данных без дублирования кода.
* **Покрытие кода (Code Coverage):** Подключила и настроила плагин **JaCoCo**. Успешно достигла **100% покрытия кода** для критически важного класса бизнес-логики сборки бургера.

📊 **Итоги покрытия кода:**

| Модуль (Класс) | Покрытие по строкам (Line) | Покрытие по ветвлениям (Branch) |
| :--- | :---: | :---: |
| `Burger.class` | ✅ 100% | ✅ 100% |

---

#### 🔹 Часть 2: Настройка сборки и отчетности
* **Автоматизация сборки:** Настроила жизненный цикл проекта в **Maven** для автоматического прогона тестов при сборке.
* **Генерация отчетов:** Настроила плагин `jacoco-maven-plugin` для автоматического формирования интерактивных HTML-отчетов по результатам тестирования.

---

### 🏃 Инструкция по локальному запуску

**Как запустить тесты и сгенерировать отчет:**
1. Клонируйте репозиторий и перейдите в папку проекта:
   ```bash
   git clone https://github.com
   cd Diplom_1
   ```
2. Выполните команду в терминале:
   ```bash
   mvn clean test jacoco:report
   ```
3. Откройте сгенерированный HTML-отчет в браузере: `target/site/jacoco/index.html`
